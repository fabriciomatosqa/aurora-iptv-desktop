# AURORA IPTV Desktop

Player IPTV para Windows e Linux, desenvolvido separadamente do projeto [AURORA IPTV Android](https://github.com/fabriciomatosqa/iptv-player).

**Versão inicial: 0.1.0 beta.** O projeto usa Python, PySide6 e SQLite, com importação M3U/M3U8, canais ao vivo, filmes, séries, favoritos, retomada e múltiplas listas.

O aplicativo não inclui listas, conteúdos ou credenciais. O código-fonte, os testes e as rotinas de compilação serão mantidos neste repositório.

> Os instaladores são gerados nos sistemas Windows e Linux por GitHub Actions; não foram validados com streams reais em PCs.
