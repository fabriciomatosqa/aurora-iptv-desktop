# AURORA IPTV Desktop 0.6.0-beta.10 — Cabeçalho Aurora

O topo do AURORA Desktop foi redesenhado para integrar a imagem da aurora boreal ao aplicativo e destacar a identidade do projeto.

- Cabeçalho ocupa toda a largura disponível da área principal, sem a antiga caixa "Lista ativa" na direita.
- Imagem da aurora recebe recorte proporcional, bordas arredondadas, camada suave de degradê, detalhes ciano e roxo e títulos legíveis.
- Barra de menu simples e discreta; versão instalada visível no próprio banner.
- Seletor "Playlist ativa" foi movido para **Configurações**, acompanhado de uma explicação de como alternar a biblioteca. A lista permanece associada aos controles existentes, sem perder favoritos nem o estado.
- Ao trocar a playlist dentro das Configurações, a seção permanece aberta e mostra o nome selecionado.
- Novos testes verificam responsividade do banner e alternância das playlists sem interferir na navegação.
- Player, importação M3U, Futebol e autoatualização silenciosa de Windows/Linux preservados.

**Atualizar pelo aplicativo:** na beta.9, abra Atualizações → Verificar atualizações agora → Atualizar agora para passar à beta.10. O Windows deve instalar silenciosamente; Debian poderá pedir autorização administrativa, depois reabrirá o AURORA.

Versão beta: confira visualmente o topo nas resoluções do seu monitor e as informações de playlists em Configurações.
